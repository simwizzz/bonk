# PokéBonk 0.7.8 离线还原报告

## 决策摘要

本仓库交付可在本机运行的离线派生客户端，保留原发布版玩法、渲染和资源，补写独立本地存档后端。真实森林运行、结算和刷新恢复通过；完整服务器、原 TypeScript 工程、通用战斗星尘和在线服务没有被声称已恢复。上传范围由用户明确指定为 `simwizzz/bonk`，未启用公开游戏托管。

## 范围与实现

截图中的游戏为 Charcher 的 PokéBonk。原站入口采集时为 v0.7.8、构建 mvgfxz8a，使用 Vite ES module 与 Three.js，未发现 Unity 构建或公开 sourceMappingURL，因此没有套用 AssetRipper/Unity 流程。

只读取得原站已明确引用的公开客户端与静态资源；没有请求账号 API、建立原站账号或接触原站存档。原始客户端未直接执行，运行检查使用经过审阅并限制外连的本地派生版。

派生版只在主 JS 中导入本地适配器并替换后端工厂，首页移除 beacon 并增加常驻离线提示。服务只监听 `127.0.0.1`，只提供静态 GET，CSP 限制外连。地图、战斗、招式、角色和图集逻辑保留。适配器使用独立 `rea.` 键，复用客户端已知的初始化、实验室、物品、任务、成就和挑战规则，支持本地票据、快照及幂等结算。

## 资源与溯源

原始集合为 1714 文件、40,175,997 字节，全部有 SHA256；包括前 151 种精灵的图集/图标/肖像/叫声、祭坛引用的未知图腾辅助图集、40 个模型及环境/UI/字体等依赖。数据表有 1025 种记录，但发行配置只开放关都 151 种。

原始集合中的 1712 项与派生版共享未改字节，另保留原始入口与主 JS，避免重复上传整份素材。原始集合处理前后路径、大小与哈希未变；派生版只修改入口和主 JS，另加适配器。详见 [来源映射](../provenance/README.md)。

提交时，GitHub 连接器负责写入仓库，1712 项静态素材封装为 `asset-archive/` 中的可校验 Base64 分片。源码保持直接可读，服务首次启动自动离线展开，素材字节与原始清单一致；没有把浏览器存档放入资源包。

三张物品/边框图未取得：`fairy-feather.png`、`tm.png`、`type-dark.png`。原请求返回 404，另一次带版本查询的请求返回 403，没有绕过访问限制或伪造原件。森林开局检查未触发它们。原客户端既存的物品图 fallback 保留。

## 真实限制

普通战斗星尘公式不在公开客户端中，因此该项奖励为 0；已知任务/成就/闪光奖励继续使用客户端规则。服务器经济、官方奖章、账号、云存档、排行、好友/战队及联网反馈没有恢复，部分原菜单和赛季文案仍保留。只支持单页本地存档，关闭战斗后可结算最近快照，不能原地续战。

未逐一通关所有角色、地图、Boss 或无尽后期。原生截图工具因无法可靠确认浏览器 URL 被自身安全检查中止，未完成原生视觉验收；headless 功能运行不冒充该验收。未启用 GitHub Pages，也未向本次指定仓库之外上传游戏资源。

接口细节与原代码偏移见 [适配器契约](adapter-contract.md)。
