# PokéBonk · REA 离线还原版

基于 PokéBonk **v0.7.8 / mvgfxz8a** 发布客户端整理的本地可玩版本。保留 Three.js 渲染、地图、角色、招式和战斗逻辑，使用独立的浏览器本地存档后端。它不是原 TypeScript 工程或官方服务器源码。

已实际验证：游客进入、初始选角、森林战斗、暂停、结束结算及刷新恢复。原项目为 [Charcher 的 PokéBonk](https://pokebonk.com/)，制作名单与来源说明保留在游戏内。本仓库为独立的离线还原成果。

## 启动

需要 Python 3.9+ 和支持 WebGL 的现代浏览器，无需安装 Python 第三方依赖。

下载或克隆本仓库，双击 `Start-Pokebonk.cmd`，或在仓库根目录运行：

```powershell
python serve_local.py --port 8765 --open
```

启动后打开 `http://127.0.0.1:8765/?lang=zh`，选“以游客身份游玩”，选择初始伙伴，然后“开始游戏”→选择角色→选择地区→“出发”。保持服务窗口开启，按 Ctrl+C 关闭服务。不要直接双击 `offline_web/index.html`。

服务仅监听本机回环地址，CSP 限制客户端连接本地资源，不代理原站 API。这里没有启用 GitHub Pages 或公开游戏服务。

静态素材以带 SHA256 清单的 Base64 分片资源包保存在 `asset-archive/`，启动时会自动校验并展开到 `offline_web/`，无需联网。入口、主 JS、本地适配器和测试直接保存在仓库中，便于检查。需要单独展开或核验资源时运行 `python scripts/prepare_client.py`；已有同名文件若哈希不符会拒绝覆盖。

## 操作与存档

WASD 移动，鼠标调整视角，空格跳跃，Shift 滑行，R 终极技，E 互动，Esc/P 暂停。攻击自动施放，升级时选择强化。

存档保存在当前浏览器、同一地址和端口下，适配器使用独立的 `rea.` 存储键。请保持使用同一个浏览器和端口，只开一个游戏页；清理站点数据、无痕窗口或更换浏览器会失去原有本地进度。关闭战斗后可结算最近快照，不能原地续战。

## 已知限制

- 账号、云存档、排行榜、官方奖章、战队/好友及联网反馈不可用。原客户端仍有部分相关入口和赛季文案，后端会明确拒绝联网操作。
- 公开客户端不包含服务器的通用战斗星尘公式，本版不猜测该公式：普通战斗星尘为 **0**。能核实的任务、成就和闪光捕获奖励继续使用保留的客户端规则，原版长期经济节奏未精确恢复。
- 当前版本开放关都 151 种；另含祭坛使用的未知图腾辅助图集。数据表中的其余种类不会因此解锁。
- `fairy-feather.png`、`tm.png`、`type-dark.png` 三张物品或边框图未取得，没有用其他图冒充原件。森林开局检查未触发这些缺图。
- 原生截图工具因无法可靠确认浏览器 URL 而停止，原生视觉验收尚未完成。自动功能运行不等同于逐角色、逐地图或通关验收。
